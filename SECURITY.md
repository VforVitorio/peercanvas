# Security policy

PeerCanvas is not yet a released product. Security-sensitive features such as peer sharing, invitation links, AI/MCP tools, XML/SVG import, and persistence are planned and are not implemented in the current scaffold.

## Reporting a vulnerability

Please use this repository's private vulnerability reporting feature. If it is unavailable, contact the maintainer through the [VforVitorio GitHub profile](https://github.com/VforVitorio). Do not publish exploit details or credentials in a public issue.

Include the affected version/commit, operating system, impact, reproduction steps, and any safe proof of concept. Do not include real diagrams, access tokens, invitation secrets, or other private data.

## Supported versions

There are no released versions yet. Once releases begin, this section will list supported versions and the process for security fixes.

## Security design

See the [sharing threat model](docs/security/sharing-threat-model.md) and [risk register](docs/security/RISK_REGISTER.md). Reports are handled by the maintainer; no response-time guarantee is published at this stage.
