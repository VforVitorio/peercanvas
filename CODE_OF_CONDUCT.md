# Community conduct

PeerCanvas aims to be a welcoming project where people can participate regardless of experience, identity, background, or location.

Expected behavior:

- Be respectful and assume good faith while addressing disagreement.
- Give actionable, specific feedback about work and ideas.
- Keep discussions focused on the project and avoid harassment, discrimination, threats, or personal attacks.
- Respect privacy. Do not publish another person's personal information or private documents.
- Report security issues privately as described in SECURITY.md.

Unacceptable behavior may be removed from project spaces. Report conduct concerns to the maintainer through the [project owner's GitHub profile](https://github.com/VforVitorio). The maintainer will review reports and decide on corrective action. There is currently no response-time guarantee.
